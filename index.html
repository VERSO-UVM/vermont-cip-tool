Budget Setup

Set the plan length, each year's estimated capital funds, and your town's information. The same budget applies across all worksheet tabs.

Annual capital capacity

A year's total is green if within local funds, amber if it needs grants, and red if it exceeds everything - meaning you'd need a bond or larger outside grant.

Existing debt service is what the town already owes each year. It comes off the top, so the plan only gets what's left.
